    Long-term memory · Oct. 2025—Jul. 2026

    GRACE-Mem

    Evidence-Centric Conversational Memory

    Designed an evidence-first memory system combining hybrid retrieval, hierarchical reranking, and bounded agentic curation.

    Role — Research lead · Retrieval and evaluation

    Explore implementation+
    • Separated graph candidate discovery, compressed-record reranking, and provenance-linked raw-dialogue reconstruction so summaries never become final evidence.
    • Combined BM25, dense entity/relation search, two-hop query-conditioned spreading activation, and hierarchical reranking.
    • Instruction-conditioned reranking raised gold-evidence recall from 34.5% to 63.4% (+28.9 points) and answer accuracy by 3.0 points.
    • Built a bounded 10-call GREP / READ / VEC curation loop with trajectory-level provenance validation, additive coverage recovery, and identity fallback.
    • Best reported results reached 86.9% on LoCoMo and 80.2% on LongMemEval across evaluated configurations.
    • BM25 + Dense
    • Graph Retrieval
    • Evidence Curation
    86.9%LoCoMo80.2%LongMemEval
